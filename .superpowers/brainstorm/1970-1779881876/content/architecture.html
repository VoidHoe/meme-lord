Comment vos potes se connectent ?

Ce choix définit toute l'architecture du projet

A

🌐 Internet — Serveur central

Un petit serveur Node.js hébergé en ligne (Railway, Fly.io ~gratis). Tout le monde se connecte à une URL. Fonctionne depuis n'importe où, même si vous jouez pas dans la même pièce.

✅ Pour

  • Marche partout (online)
  • Pas de config réseau
  • Scalable

⚠️ Contre

  • Faut déployer un serveur
  • Latence réseau
B

🏠 LAN — Un des potes héberge

L'app de l'hôte embarque le serveur WebSocket. Les autres entrent son IP local (192.168.x.x). Parfait pour les sessions gaming en réseau local ou via VPN (Hamachi, ZeroTier).

✅ Pour

  • Zéro coût / hébergement
  • Ultra rapide (LAN)
  • 100% local

⚠️ Contre

  • Même réseau requis (ou VPN)
  • L'hôte doit lancer l'app en premier
C

🔀 Hybride — Les deux

L'app peut fonctionner en mode "hôte local" ou se connecter à un serveur distant selon la config. Le plus flexible mais aussi le plus de dev.

✅ Pour

  • Maximum de flexibilité
  • LAN = 0 latence, cloud = partout

⚠️ Contre

  • Plus de code à écrire
  • Config plus complexe
