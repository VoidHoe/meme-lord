Quel type d'audio tu veux ?

L'audio c'est la feature principale que tu veux ajouter par rapport à MemeDrop

A

🎤 Message vocal live

Tu enregistres un message vocal dans Discord (note vocale), le bot le capte et le joue en overlay sur tous les écrans. Comme un walkie-talkie de mème.

Exemple : tu envoies un voice message Discord dans le channel → ça s'affiche avec une image + ta voix qui dit "GG EZ" sur l'écran de tes potes
B

🔊 Sons / SFX prédéfinis

Une bibliothèque de sons qu'on charge dans l'app (boom, air horn, voix TTS, etc.). Tu tapes /sound airhorn dans Discord pour déclencher.

Exemple : /drop pepehands.gif + /sound sadviolin → GIF + son triste sur tous les écrans
C

🎵 Les deux

Messages vocaux live et bibliothèque de sons. Tu peux aussi attacher un fichier audio à n'importe quel drop d'image/GIF.

Exemple : /drop image + audio → image + son jouent ensemble. Ou juste /sound pour un son seul.
